# Manual de Usuario — SENA Gestión Educativa

## Qué

Generar un manual de usuario completo, claro e instruccional en formato Markdown (`MANUAL_DE_USUARIO.md`) que sirva como guía operativa paso a paso para todos los perfiles de usuario del sistema: Coordinadores Académicos, Instructores, Administradores del Sistema y Personal de Dirección.

## Para qué

- **Capacitación:** Permitir a los funcionarios del SENA aprender a usar el sistema de forma autodidacta.
- **Referencia operativa:** Servir como consulta rápida para procedimientos específicos (crear ficha, programar instructor, gestionar permisos).
- **Reducir soporte:** Disminuir las consultas repetitivas al equipo técnico al documentar las respuestas a preguntas frecuentes.

## Criterios de aceptación

- [ ] El archivo `MANUAL_DE_USUARIO.md` se crea en la raíz del proyecto.
- [ ] Incluye marcadores de captura de pantalla estandarizados en cada sección de pantalla.
- [ ] El lenguaje es claro, instructivo y no excesivamente técnico.
- [ ] Usa negritas para nombres de botones, campos y opciones de menú.
- [ ] Usa listas numeradas para pasos secuenciales y viñetas para explicaciones.
- [ ] Cubre los 11 módulos del sistema más el panel de administración.
- [ ] Incluye sección de FAQ y glosario SENA.
- [ ] Todos los campos, botones y flujos descritos corresponden al código real del repositorio.
- [ ] `npm run lint` sin errores nuevos.
- [ ] Commit + push.
