# Evidencia de Innovación Administrativa — Informe Técnico Institucional

## Qué

Generar un documento técnico institucional en formato Markdown (`INFORME_INNOVACION_ADMINISTRATIVA.md`) que sirva como evidencia formal de la innovación administrativa liderada por el subdirector Fernando Gonzales Torres en el Área de Gestión Administrativa del Centro de Formación SENA.

El informe documenta la plataforma **SENA Gestión Educativa (SenaSchedule)** como producto tecnológico desarrollado para optimizar la gestión de infraestructura educativa, talento humano y programación académica.

## Para qué

- **Evidencia institucional:** Documentar formalmente el desarrollo de una herramienta tecnológica como parte de las actividades de innovación administrativa de la subdirección.
- **Trazabilidad técnica:** Consolidar en un solo documento el alcance técnico real del sistema (stack, arquitectura, módulos, API, base de datos, despliegue).
- **Documentación de referencia:** Servir como insumo para evaluaciones de gestión, informes de novedad o presentaciones ante la dirección regional.
